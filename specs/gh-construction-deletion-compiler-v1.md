# GH Construction Deletion Compiler v1

Status: CANONICAL specialization of Sanctuary / Build Bible for the ~1,000 ft² one-story 2-bed/2-bath GH.

## Objective
Reduce total installed and lifecycle burden by deleting unnecessary construction before optimizing the construction that remains.

Canonical order:

REQUIREMENT
-> DELETE UNNEEDED PARTS
-> DELETE UNNEEDED OPERATIONS
-> DELETE UNNEEDED UNIQUE DETAILS
-> SIMPLIFY TOPOLOGY
-> STANDARDIZE/REPEAT
-> MECHANICALLY ASSIST NECESSARY WORK
-> OPTIMIZE PROCUREMENT/SEQUENCING
-> BUILD

Core laws:
- DELETE PARTS BEFORE FINDING CHEAPER PARTS.
- DELETE OPERATIONS BEFORE MAKING OPERATIONS FASTER.
- DELETE UNIQUE DETAILS BEFORE OPTIMIZING DETAILS.
- A mechanism is never promoted into a requirement merely because it is clever or proven.
- A clever GH feature should preferably delete construction, materially reduce lifecycle burden, or satisfy a protected requirement.

## Construction element justification
Every material/layer/member/joint/opening/penetration/detail MUST be traceable to at least one consequential requirement class:
LOAD · WATER · AIR · HEAT · FIRE · SOUND · ACCESS · SERVICE · DURABILITY · FINISH · CODE · HUMAN USE.

If an element has no independent requirement owner, it is a deletion candidate. If multiple elements satisfy the same requirement, test whether functions can legitimately collapse into fewer layers/details without violating protected constraints.

## Proven low-complexity candidates
These are challengers, not mandated mechanisms:
- advanced/optimum-value framing where engineering/code/site allow, including wider stud spacing, reduced redundant studs, aligned load paths, and simplified headers/top plates where structurally valid;
- stacked/aligned structural load paths across roof/wall/foundation;
- compact boring structural box before articulation;
- simple roof geometry with repeated spans and minimal penetrations;
- conventional trusses or other mature repetitive framing when adequate;
- foundation system competition based on soil/topography/code/installed lifecycle cost, not material volume or novelty;
- dimensional coordination around commodity sheet/framing/insulation/cabinet/door/truss modules where this reduces cuts, scrap and unique operations without distorting human use;
- repeated openings/details/flashing/trim assemblies where equivalent;
- opening-count reduction before cheapening openings;
- geometric water management before membrane/pump dependence: site grading, drainage, roof shedding, gravity routes, protected dry structural island;
- continuous air/water/thermal control layers rather than patchwork correction after trades diverge;
- compact conditioned distribution and short HVAC/service paths;
- actual-load sizing plus justified reserve instead of blanket oversizing;
- standardized penetrations, service entries and transitions;
- inspection-before-cover as an upstream defect-prevention gate;
- permanent architecture separated from replaceable equipment: SPACE + ACCESS + ROUTE + ATTACHMENT + UTILITY INTERFACE, then replaceable payload.

## GH-specific topology
For the GH, topology attacks cost before transport mechanisms:
COMPACT FOOTPRINT
-> SHARED BOUNDARIES
-> WET/SERVICE CORE CONCENTRATION
-> PRODUCTIVE WALLS
-> PASSIVE SHORTCUTS
-> MOBILE/DEPLOYABLE CAPABILITY
-> POWERED MECHANISM ONLY FOR GENUINE NEED.

No conventional hallway by default. Laundry/pantry/storage are operating envelopes/capabilities, not automatic dedicated rooms. Passive adjacency should solve short-distance movement before specialized logistics.

## Foundation / earthwork discipline
Canonical sequence:
PARCEL/SITE SELECTION
-> MICRO-SITING
-> WATER/DRAINAGE ROUTING
-> MINIMUM EARTHWORK
-> FOUNDATION REQUIREMENT
-> CHEAPEST ADEQUATE QUALIFIED FOUNDATION.

Reject:
- technology used to subsidize a bad parcel or bad building location;
- concrete-minimization theater where installed cost rises;
- Wafflemat/other system religion;
- uniform excavation/earth-coupling when terrain does not require it;
- shallow earth-contact design drifting into basement complexity;
- unnecessary retaining-wall proliferation;
- short-lived service components buried in slab merely for convenience;
- spoil export/import ping-pong when suitable reuse exists;
- zero-export dogma when spoil is unsuitable;
- repeated equipment mobilization that can be batched.

## Cost semantics
Savings are only real after parent recompilation. Track separately:
- area truly deleted from exterior envelope;
- perimeter/roof/foundation/enclosure deleted;
- partitions/openings/finishes deleted;
- MEP length/penetrations/service complexity deleted;
- labor operations deleted;
- unique detail count deleted;
- mobilizations/rehandling deleted;
- material/scrap deleted;
- mechanism/additional-feature cost introduced;
- maintenance/failure/service burden introduced.

Recovered interior volume is not automatically construction savings unless it permits actual envelope/material/labor deletion or materially improves capability/lifecycle burden.

## Stop condition
Stop shrinking/simplifying when the next deletion materially worsens protected constraints such as accessibility, sleep/restoration, privacy/acoustics, serviceability, resilience, furniture/operating clearances, ordinary usability, or total lifecycle burden.

## Anti-pattern / failure canon
- CHEAPER-PART MYOPIA: optimize unit price while unnecessary parts remain.
- FASTER-WASTE: mechanize or batch an operation that should be deleted.
- UNIQUE-DETAIL PROLIFERATION: every junction becomes bespoke.
- MATERIAL-LAYER ACCRETION: each trade adds a layer without whole-assembly recompilation.
- STRUCTURAL MISALIGNMENT TAX: compensating members/material caused by avoidable load-path discontinuity.
- ROOF COMPLEXITY TAX: valleys/dormers/bump-outs/penetrations without sufficient lived-state value.
- OPENING CONFETTI: windows/doors added without accounting for interrupted framing/enclosure/finish work.
- MODULE DICTATORSHIP: commodity dimensions distort actual human requirements.
- ADVANCED-FRAMING RELIGION: OVE used where loads, shear, attachment, fire, acoustics or local practice make it inferior.
- FOUNDATION RELIGION: favorite foundation selected before geotechnical/site requirements.
- MEMBRANE HEROISM: expensive waterproofing compensates for bad water geometry.
- CAPACITY ROUND-UP: systems oversized by habit rather than demand + justified reserve.
- SERVICE BURIAL: replaceable/maintained systems entombed in permanent assemblies.
- INSPECTION DEBT: defects hidden before cheap verification.
- PREFAB/TOOL FETISH: factory/jig/lift/process introduced without deleting enough labor, risk or variability.
- STANDARDIZATION OVERREACH: repetition erases a consequential local difference.
- DIY FANTASY PRICING: tools, mistakes, time, coordination and schedule treated as free.
- SAVINGS MIGRATION: one subsystem saves while another inherits greater cost.
- SHRINKAGE THEATER: nominal ft² efficiency rises but envelope/cost does not fall.

Polar rule: boring baseline remains in every competition. Simplification is not minimalism-for-its-own-sake; every deletion must preserve required reality.
