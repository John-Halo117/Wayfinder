# Changelog

## 0.1.0-alpha.19 — 2026-08-17

- Added Sparse Bipolar Dimensional Trend Tensor (SBDTT) as the default sparse evaluated projection when several orthogonal dimensions materially change interpretation or action.
- Preserved polarity, operational state, epistemic state, and trend as orthogonal semantics; explicitly rejected neutral=unknown and universal goodness scores.
- Added universal spatial/jurisdictional/functional scope semantics.
- Added derived multi-axis classification semantics with stable identity, valid-time recomputation, provenance, and contested-class preservation.
- Folded Weather Fabric / External Local Twin semantics into an Environmental External-World Projection rather than a parallel world model.
- Generalized magnitude/frequency/duration/persistence/timing/recovery/variability/trend/tails/compound-state operators beyond weather-specific ownership.
- Updated EWS to treat SBDTT as a downstream disposable projection, not factual state storage.
- Recorded the evaluated-projection architecture in ADR-0002.

## 0.1.0-alpha.18 — 2026-08-16

- Canonicalized External World State (EWS) as the qualified derived state boundary produced by Reasoning.
- Preserved ARK ownership of durable evidence/provenance and Interpretation ownership of candidate meanings.
- Defined Baseline, Successor, Reachability, and Twin semantics without selecting runtime or storage mechanisms.
- Added `Operative State` compatibility and deprecated the ambiguous `Current Head` alias.
- Registered EWS in the required contract set and ownership matrix.
- Recorded the migration and rollback boundary in ADR-0001.
- No production runtime, schema implementation, graph engine, database, or language-specific API has been introduced into Wayfinder.
