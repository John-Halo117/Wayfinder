# Derived Classification

**Canonical semantic owner:** Wayfinder  
**Version:** `0.1.0-alpha.19`

## Core Law

**Identity is stable; classification is derived.**

Classification is a projection from qualified evidence and External World State. It MUST NOT be treated as an intrinsic identity field, an authority grant, or a parallel truth store.

## Multi-Axis Classification

An entity may simultaneously occupy multiple independent classification axes, including physical, ecological, hydrological, geological, climatic, cultural, economic, agricultural, administrative, infrastructure, hazard, or other domain-relevant axes.

Independent axes MUST NOT be collapsed into one universal class score.

## Membership Shape

Use the cheapest adequate membership representation:

- Boolean for genuinely discrete membership;
- set-valued membership for multiple simultaneous classes;
- vector or score for graded membership;
- distribution for uncertainty over membership.

Membership strength is not epistemic confidence.

## Derivation Contract

A nontrivial derived classification must preserve, where material:

- input evidence/state references;
- derivation rule/model/version;
- scope/population;
- valid time;
- provenance;
- uncertainty or contestation;
- invalidation / recomputation conditions.

## Temporal Semantics

Mutable classifications are valid-time projections. Reclassification changes relations/projections, not canonical identity.

Material reclassification may emit an Event and supersede a prior classification projection.

## Contested / Interpretive Classes

Cultural, economic, narrative, social, or other interpretive classes preserve epistemic type and competing qualified claims where boundaries or definitions are contested.

A useful label does not become objective physical fact merely because it is convenient.

## Ontology Admission

A proposed new class or axis is admitted only after attempting, in order:

`alias -> composition -> reduction -> generalization -> existing primitive + parameters -> new canonical concept`

A new label does not imply a new architectural owner.

## Consumer Law

Land, Habitat, Agriculture, Risk, Infrastructure, Culture/History, Economics, Policy, News, Procurement, and other domains consume shared classification relations. They MUST NOT create separate classification truth stores for the same semantics.
